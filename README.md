Welcome To My Personal Website.
This Project uses JavaScript combined with HTML5 and about a thousand lines of CSS to make a beautiful animated page.

I've used particular colors to design the website-
    #D4D4D4; #A3A3A3; #484848; #969696; #121212; #000000; #FFFFFF; #888888; #c5c4c4; #282828; #363636; 
And for magnetic cards- rgba(80, 160, 255, 0.35)

I collected assets such as the stickers for the website from pinterest, the music track (In Motion by Trent Reznor) from [link](audio.com) 

For the Terminal Bot, I used three GEMINI_API_KEY (s), 2 as fallback. I Saved the API keys in my vercel environment variables to keep them secure.

And yes, I **have** to Tailwind CSS now because those 800 lines are _**monstrous.**_
